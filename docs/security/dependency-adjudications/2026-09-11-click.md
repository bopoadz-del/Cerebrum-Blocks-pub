## PYSEC-2026-2132

- Aliases: CVE-2026-7246, GHSA-47fr-3ffg-hgmw
- Package: click
- Installed pin (lock): 8.1.8
- pip-audit `fix_versions`: 8.3.3
- Latest published click: 8.5.0

### Decision: accept_constrained

The published fix is **8.3.3**, not a ceiling. A prior workplan that wrote
`click<8.2` into a pin file would have been a scanner story.

This Store graph really cannot take 8.3.3 today. `gTTS 2.5.4` (voice block,
`requirements.txt`) declares:

    click<8.2,>=7.1

That is `gTTS`'s Requires-Dist on PyPI. `gTTS 2.5.4` is still the latest
published gTTS. Uvicorn declares `click>=7.0` with no ceiling. We do not
add a `click<8.2` line of our own.

When a newer gTTS drops the `<8.2` cap, this note is stale: upgrade click
to at least 8.3.3 and delete the registry row.

### Evidence

- `importlib.metadata.requires("gTTS")` contains `click<8.2,>=7.1`
- `requirements.txt` does not invent a click ceiling
- Voice block (`app/blocks/voice.py`) imports `gtts.gTTS`
